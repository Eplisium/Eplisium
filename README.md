## 👋 Hey, I'm Zach

I build software across the whole stack: AI agent tooling, web apps, game server infrastructure, native desktop apps, and the occasional synth. I'm also a music producer with far too many ideas and not enough hours.

- 🔭 **Right now:** AI agent tooling, native macOS apps in SwiftUI, and audio software in Rust
- 🏢 **Building through:** [Unknown Projects](https://github.com/Official-Unknown-Projects), shipping client sites and products
- 🎮 **Always tinkering with:** game servers, modding, and reverse engineering
- 🎵 **Off the clock:** producing music
- 💬 **Ask me about:** agents, Next.js, Python automation, Minecraft and WoW servers

> *"Lots to do in this world. Don't stop being yourself."*
